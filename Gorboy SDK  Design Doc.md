# Gorboy SDK Design Document ## 1. Philosophy We treat developers and players like adults. Your ethics, your rules—your problem. Our job: tools that never hide. Every stake, every win, every cut, every pot—on display. We don't judge. We just make sure you can't lie. ## 2. Introduction 2.1 Purpose Turn any game into Gorboy-native with zero friction. Tokens = score points. Value? That's outside. Play stays play. 2.2 Target Audience Indie devs, web3 tinkerers, anyone who wants crypto flavor without crypto mess. 2.3 Scope - Wallet connector (EVM/SVM) - Escrow engine - Verified transparency badges - Leaderboards & scoreboards - NFT avatar linking (future) Out: fiat on-ramps, wallet issuance, transaction signing. ## 3. Game Flavors 3.1 Proof-of-Play (Mining) Game submits proofs → SDK mints coins. Rate scales with demand. Predictable. Low baseline inflation. 3.2 PvP Stake → play → win → SDK splits pot. House rake optional. Up to 10%. Goes dev or pool. 3.3 House-vs-Player You stake. House stakes. SDK locks. Game ends. Money flows. House balance shown live. ## 4. Core Mechanics 4.1 Escrow Coins preload—no wallet popups. Held until: - Round ends → payout - Disconnect → offline finish → auto-settle - Invalid → full refund - Timeout → rule-based airdrop 4.2 Transparency Engine Every stat gets a Gorboy Verified Badge : - Live QR-ish glyph - Refreshes every 30s - Tap → lands on gorboy.wtf/verify/hash - Chain-signed. Non-scrapeable. Unfakeable. 4.3 Scoreboard & Leaderboards - Real-time - Wallets (opt-in show) - Stakes, wins, jackpots - Multi-winner split logic auto-handled ## 5. Token Handling - In-game: chips. No cash value. - Out-game: trade, hold, sell—like a collectible. - SDK never hints convert. It doesn't blink. ## 6. Wallet Integration - Connect Phantom, MetaMask, Backpack—any SVM/EVM. - Reads NFTs for profile avatars. - No write access unless game explicitly asks. ## 7. Fees & Economics - Rake flows auto: dev wallet or Gorboy pool. - Baseline mining keeps token alive—low, steady. - More players = more velocity = stronger ecosystem. - Gorboy profits: NFT drops, gas fees, token growth. ## 8. Risks & Responsibility Game devs and players assume full fiduciary responsibility. Gorboy SDK gives mechanics—nothing else. Compliance? Yours. Copyright? Yours. Regional law? Yours. We don't block, we don't bless. Own it. ## 9. Enforcement Spoof the badge? SDK access revoked. One report → audit → ban. No exceptions. All set—ready for GitHub.
