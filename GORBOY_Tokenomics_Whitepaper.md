## SELF-REGULATING MINING SYSTEM

GORBOY uses a dynamic adjustment mechanism to balance mining rewards without manual intervention.

### How It Works

**Base Rate:** 1 GORBOY per mining unit (game action/achievement)

**Adjustment Formula:**  
```
tokens_per_action = (current_pool_size / 200,000,000) × base_rate
```

**Examples:**
- Pool inflates to 220M → players earn 1.1 GORBOY per action
- Pool depletes to 180M → players earn 0.9 GORBOY per action

### Key Insight
**Mining volume does NOT affect token price.** Only market supply/demand dynamics impact value. The adjustment mechanism purely controls *quantity earned per action*, ensuring:
- Mining pool never fully depletes (asymptotic decay)
- Early adopters earn maximum quantity at highest unit value
- Late adopters earn less quantity, but token appreciates as adoption grows
- No panic burns, no dilution surprises

### What This Means

**For Investors:**  
Your holdings are shielded from gameplay volume fluctuations. Controlled supply becomes more valuable with adoption. Inflation is predictable and diminishes over time.

**For Gamers:**  
Early entry means higher rewards per action. As player base grows, rewards per action decrease, but token value increases. Solo or multiplayer, consistent ROI based on effort.

**For Developers:**  
Transparent reward math. No guessing if your game will drain the treasury. Build once, scale indefinitely.

Developers must display available wallet balance so maximum payout is always transparent. If promised rewards exceed reserves, developer tops up from their allocation.

Games can combine player stakes with background mining rewards or fee based jackpot pools.
